Moderation tool for discussions.

Give select users the ability to close discussions, give strikes to users, and ban users from opening any other discussions outright (and also the ability to unban them).


Closers can close discussions
Strikers can strike users
Moderators can do all of the above + ban/unban

Can enable/disable strike feature and only use this to close/ban(/unban) by specifying the number of strikes a user can receive before being autobanned.

Commands:

`/strike` -> strikes the discussion opener
`/ban <reason>` -> Bans the discussion opened with saved reason
`/unban @user` -> Unbans a user

The ban reason is `__system__` if user is banned by strikes.
